## 一、P1 级缺失（影响核心功能）

### 1.1 客户端管理页面（frontend missing）

**问题**：后端 API 已完全实现（ClientController、ClientGroupController、ClientVersionController），但管理后台缺少对应的前端页面。

| 缺失页面                          | 后端 API 状态 | 页面文件  |
| ----------------------------- | --------- | ----- |
| clients.html（客户端列表/审批/封禁/命令）  | ✅ 完整      | ❌ 不存在 |
| client-groups.html（客户端分组管理）   | ✅ 完整      | ❌ 不存在 |
| client-versions.html（客户端版本管理） | ✅ 完整      | ❌ 不存在 |

**影响**：管理后台无法查看已注册的 PE 客户端、无法审批/封禁、无法管理客户端分组和版本。

**建议处理时机**：Phase 2 UI 补齐

### 1.2 管理后台侧边栏菜单可能缺失

**问题**：新增模块（clients、client-groups、client-versions、pe-versions、pe-customize 等）的菜单入口需要确认是否已添加到 admin/index.html 的侧边栏。

**影响**：即使页面已创建，若菜单缺失则管理员无法访问。

**建议处理时机**：Phase 2 UI 补齐

***

## 二、P2 级缺失（功能完整性）

### 2.1 Windows 客户端安装向导 UI 未集成（partial）

**问题**：InstallWizardViewModel.cs 已集成 ZsTaskBuilder 全流程（下载 10 项资源 + BCD 注入 + 重启），但：

- SoftwareList 参数收集 UI 未实现（当前为 TODO 占位）

- DriverId 参数收集 UI 未实现（当前为 TODO 占位）

- 驱动包/软件包的版本选择界面未对接后台 API

**影响**：Windows 端下单时无法选择要安装的软件包和驱动包。

**建议处理时机**：Phase 2 UI 补齐

### 2.2 驱动/软件编辑页面缺少 file\_path 字段

**问题**：drivers.html 和 software.html 的编辑表单（showEditModal）中缺少 `file_path` 和 `file_name` 字段，管理员无法查看或修改已上传文件的路径。

**影响**：上传后无法确认文件存储位置，也无法手动修正路径。

**建议处理时机**：Phase 2 UI 补齐

### 2.3 数据库迁移未执行

**问题**：`database/migration_r7_assets.sql` 需要手动在 MySQL 中执行，才能为 `zs_pe_versions` 表添加 boot.wim/boot.sdi/agent.exe 的字段。

**影响**：PE 资产上传接口会因字段不存在而报错。

**⚠️ 需要你操作**：在 phpMyAdmin / Adminer 中执行 `database/migration_r7_assets.sql`

## 三、P3 级缺失（联调验证）

### 3.1 VM/真机联调未进行

**问题**：P3 后端 API 端点已全部实现，但未经过完整的 VM 或真机联调验证。

**待验证内容**：

- PE 资产上传 → 前端 pe-versions.html 上传控件能否正常提交

- PE 资产下载 → 客户端 PeAssetDownloader 能否正确下载 boot.wim/boot.sdi/agent.exe

- 驱动/软件下载 → 客户端 DriverPackageDownloader/SoftwarePackageDownloader 能否正确调用 clientDownload 端点

- 系统镜像下载 → 客户端 SystemImagePreDownloader 能否正确调用 images/{id}/clientDownload

**建议处理时机**：Phase 3 联调

### 3.2 驱动/软件表缺少 file\_hash 自动计算

**问题**：`upload()` 方法上传文件后未计算并保存 `file_hash`（SHA-256），导致客户端下载后无法校验文件完整性。

**影响**：文件传输损坏无法检测。

**建议处理时机**：Phase 3 联调

## 四、已知技术债务

### 4.1 driver 表字段名不一致

**问题**：数据库 `zs_drivers` 表使用 `device_type` 字段，但上传表单使用 `type`，前端详情页使用 `item.type`，后端代码需注意映射。

**影响**：已修复前端上传映射 `type` → `device_type`，但需验证。

### 4.2 SoftwareController 缺少 silent\_install 和 os\_support 字段

**问题**：`SoftwareController::create()` 接收 `silent_install` 和 `os_support` 参数，但 `upload()` 方法中未设置这些字段，软件上传后静默安装参数为空。

**影响**：PE 端安装软件时可能无法静默安装。

**建议处理时机**：Phase 2 UI 补齐
