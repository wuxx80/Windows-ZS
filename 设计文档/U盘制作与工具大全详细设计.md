# 第 1 章 U盘制作详细设计

## 1.1 需求与边界

| 项 | 说明 |
|----|------|
| 入口 | 首页「💿 U盘制作」卡片（WinPE 端 + Windows 端） |
| 职责 | 把 PE 系统写入可移动 U 盘，做成启动盘，支撑「U盘引导 → 进 PE → 自动续装」闭环 |
| 破坏性操作 | 格式化 U 盘、清空分区、写引导 —— 必须护栏 + 二次确认 |
| 与现有能力的关系 | 复用 DeviceService.GetDiskInfo()（已能枚举磁盘/分区/卷）、DiskPartService、ApiService |
| 依赖后端 | zs_pe_versions（PE 版本）、zs_pe_customize（PE 定制 build 产物）、zs_software（可选附加工具） |

**双端职责一致**：U盘制作属于「进 PE」辅助环节，双端行为一致（都是真实写盘，无 Windows/WinPE 职责差异，与一键装机不同）。

**交互闭环：**
- 步骤① 进入自动枚举可移动磁盘；无可移除盘 → 空状态「请插入 U 盘后点刷新」

## 1.4 核心逻辑

### 1.4.1 可移动磁盘枚举（复用 + 增强）

```csharp
// DeviceService.GetDiskInfo() 已返回 InterfaceType（"USB"/"SCSI"/...）
// U盘判定增强：InterfaceType=="USB" 或 MediaType=="Removable Media"（Win32_LogicalDisk.MediaType）
// 需排除：系统盘（盘符含 System 卷 / Boot 卷 / 页面文件所在盘）、容量为 0 的异常盘
```

### 1.4.2 安全校验（写盘前强制）

| 校验 | 规则 | 结果 |
|------|------|------|
| 是否可移除 | MediaType=Removable 或 InterfaceType=USB | 否 → 拒绝 |
| 是否系统盘 | 目标盘含系统/启动/页面文件分区 | 是 → 拒绝 |
| 容量下限 | ≥ 512MB（PE 最小占用） | 否 → 拒绝 |
| 二次确认 | 执行页输入盘号与所选一致 | 否 → 禁止执行 |

### 1.4.3 格式化与分区（DiskPart 脚本）

```
select disk {N}
clean
convert gpt            // UEFI+Legacy 双引导建议 GPT；仅 Legacy 用 MBR
create partition primary
format fs=exfat quick  // 或 fat32 / ntfs
assign
```

> 说明：`convert gpt` 仅当引导类型需要 UEFI 支持时执行；单分区 + 双引导采用「FAT32/exFAT 单分区 + 根目录放 EFI\BOOT\bootx64.efi」的兼容方案（多数 U 盘 PE 通用做法），无需拆分 ESP。

### 1.4.4 写引导

| 引导类型 | 做法 |
|----------|------|
| UEFI | 拷贝 PE 内 EFI\BOOT\bootx64.efi → U 盘 `EFI\BOOT\`（U 盘启动标准路径）；可选 bcdboot 重建 BCD |
| Legacy | `bootsect.exe /nt60 X:`（X=U 盘盘符），写入 MBR 引导代码 |
| UEFI+Legacy 双引导 | 两者都做：EFI 目录 + bootsect /nt60（多数 PE ISO 自带兼容引导） |

### 1.4.5 PE 源获取与解压

- 服务器：`GET /peVersions/:id/download` 下载到 `C:\ZS_Cache\pe\`，校验 file_hash
- 本地文件：直接读取 .iso/.wim
- ISO 解压：Windows 10+ 用 `Mount-DiskImage`（PowerShell）挂载后拷贝到临时目录，再复制到 U 盘；或客户端内置 7z.dll 解 ISO（备选）。解压后释放镜像

### 1.4.6 进度上报（本地 UI，不写服务端任务）

U盘制作不产生装机任务，进度仅本地 UI 逐条回填（复用一键装机执行页的 SetExec/AddLog 模式）。

## 1.5 实现步骤（代码层面）

1. **UDiskService.cs**（新建，双端各一份）
   - `List<RemovableDisk> GetRemovableDisks()`：基于 DeviceService + MediaType 过滤，返回盘号/型号/容量/盘符/文件系统/卷标/已用/可移除标记
   - `ValidateTarget(disk)`：1.4.2 四项护栏
   - `Task<DiskResult> WriteAsync(WritePlan plan, IProgress<StepProgress>)`：格式化 → 拷贝 → 写引导 → 拷入客户端 → 校验，逐步回调进度
   - `DownloadPeAsync(peId)`：调 /peVersions/:id/download，带进度 + 断点续传 + 哈希校验
2. **Models**：`RemovableDisk`、`WritePlan`、`PeVersionInfo`（对齐 ApiResponse 风格）
3. **UDiskViewModel.cs**（四步状态机，模式完全复用 InstallWizardViewModel：CurrentStep/CanNext/CanPrevious/Progress/Logs）
4. **UDiskWindow.xaml**（四步向导 UI，样式资源复用主窗口；破坏性警示用红色文字 + 输入盘号确认框）
5. **双端接线**：MainWindow.xaml.cs 的 `OnUsbClick` 改为打开 UDiskWindow（替换 NotifyNotImplementedCommand）；Windows 端 Usb 占位 StackPanel 移除
6. **后端**：`PeVersionController` 增加 `clientList()` / `clientDownload()`；route/admin.php 加 `GET /api/v1/peVersions`、`GET /api/v1/peVersions/:id/download`（或复用 admin 路由，二选一）
7. **ApiService.cs**：新增 `GetPeVersionsAsync()`、`DownloadPeAsync()`（双端）

## 1.6 安全护栏与异常处理

- 写盘前：4 项校验 + 盘号二次确认 + 红色警示（"将清空数据"）
- 执行中：可暂停/取消（DiskPart 与拷贝间检查取消标记）；禁止重复触发
- 失败：记录失败步骤与原因，提示用户可重新执行；不得把 U 盘置为半可用状态而无提示
- 多实例：写盘时锁定目标盘号，防止用户同时打开两个窗口操作同一 U 盘
- 权限：写盘需管理员权限（DiskPart/bootsect），启动时检测，无权限引导用户以管理员运行

# 第 5 章 风险与注意事项

1. **写盘破坏性**：所有格式化/写引导必须护栏 + 盘号二次确认 + 红色警示；真机验证优先在虚拟机/闲置 U 盘上进行
2. **引导兼容性**：UEFI/Legacy 双引导方案需在真实机器验证（部分旧机只认 Legacy MBR）
3. **ISO 解压/引导工具**：Mount-DiskImage 与 bootsect 依赖系统组件，PE 环境与正常 Windows 行为需分别验证
4. **版权**：仅分发开源/免费工具；商业工具由用户自备，提供「打开目录」引导，禁止随包分发破解/侵权软件
5. **资源占用**：PE 文件较大（数百 MB~GB），下载需断点续传 + 进度 + 哈希校验；U 盘容量不足前置拦截
6. **多实例/并发**：写盘与运行工具时锁定目标资源，防止窗口重复触发
