## 1. 窗口规格与布局

### 1.1 窗口基本规格

| 属性 | 值 | 说明 |
|------|-----|------|
| 默认宽度 | 900px | 固定尺寸，不可水平缩放 |
| 默认高度 | 640px | 固定尺寸，不可垂直缩放 |
| 最小宽度 | 800px | 低于此值出现滚动条 |
| 最小高度 | 580px | 低于此值出现滚动条 |
| 窗口样式 | 无边框 | 自定义标题栏，统一风格 |
| 启动位置 | 屏幕居中 | 主显示器正中央 |
| 圆角 | 0px | 直角窗口，与 PE 风格一致 |
| 背景色 | #F5F6FA | 浅灰背景，区分内容区 |
| 阴影 | 无 | PE 环境无窗口阴影 |

### 1.2 窗口层级结构

```
┌──────────────────────────────────────────────────────────────────┐  y=0
│ 标题栏 (h=40px)                                                  │
├──────────────────────────────────────────────────────────────────┤  y=40
│ 步骤导航栏 (h=48px)                                              │
├──────────────────────────────────────────────────────────────────┤  y=88
│                                                                  │
│  内容区域 (h=≈452px，可滚动)                                      │
│                                                                  │
│                                                                  │
├──────────────────────────────────────────────────────────────────┤  y=540
│ 底部操作栏 (h=54px)                                              │
├──────────────────────────────────────────────────────────────────┤  y=594
│ 底部安全区 (h=46px) 预留系统任务栏区域                            │
└──────────────────────────────────────────────────────────────────┘  y=640
```

### 1.3 标题栏设计

```
┌──────────────────────────────────────────────────────────────────┐
│  ── ZS 装机助手 v2.1.0                    [⚙] [─] [□] [✕]    │
└──────────────────────────────────────────────────────────────────┘
  ↑ 图标+标题 (左对齐, 16px, #333)    ↑ 设置 ↑最小化 ↑最大化 ↑关闭
```

标题栏规格：
- 高度：40px，背景色 #FFFFFF
- 底部边框：1px solid #E8E8E8
- 标题文字：14px，#333，Segoe UI / 微软雅黑
- 图标：16x16px，左侧 12px 间距
- 按钮：右边距 4px，32x32px，悬停色 #E8E8E8

### 1.4 窗口拖拽行为

- 鼠标在标题栏按下 → 启动拖拽
- 拖拽过程中窗口半透明（opacity: 0.85）
- 释放鼠标 → 窗口定位到新位置
- 窗口边缘对齐到屏幕边缘时 → 贴边吸附（吸附阈值 8px）
- 双击标题栏 → 不触发最大化（PE 环境无此需求）

## 2. 步骤导航栏

### 2.1 导航栏布局

```
┌──────────────────────────────────────────────────────────────────┐
│  ● ① 环境检测 ────→ ○ ② 选择镜像 ────→ ○ ③ 目标磁盘 ────→     │
│                                           ○ ④ 安装选项 ────→    │
│                                           ○ ⑤ 确认 ────→ ⑥ 执行 │
└──────────────────────────────────────────────────────────────────┘
```

### 2.2 步骤项规格

| 状态 | 图标 | 文字颜色 | 背景 | 连线颜色 |
|------|------|----------|------|----------|
| 当前 | ● 蓝色 #1890FF | #1890FF 加粗 | 透明 | - |
| 已完成 | ✓ 绿色 #52C41A | #52C41A | 透明 | #52C41A |
| 待完成 | ○ 灰色 #BFBFBF | #BFBFBF | 透明 | #BFBFBF |
| 错误 | ✕ 红色 #FF4D4F | #FF4D4F | 透明 | #FF4D4F |

- 高度：48px，背景色 #FFFFFF
- 底部边框：1px solid #E8E8E8
- 步骤项间距：8px
- 连接线：2px 实线，宽 24px，垂直居中
- 步骤编号：12px 圆形，直径 24px
- 步骤文字：13px，与编号间距 6px
- 点击已完成的步骤 → 可跳回（点击待完成步骤无效）

### 2.3 导航栏状态切换逻辑

- 当前步骤完成后 → 自动跳转到下一步，高亮更新
- 当前步骤失败 → 导航栏该步骤显示 ✕ 红色
- 点击已完成步骤 → 回到该步骤，保留已填数据
- 未完成步骤不可点击（灰色禁用态）
- 当步骤数超过 6 时 → 显示步骤编号不显示文字

### 3.2 检测项逐行状态变化

每一项检测有 4 种状态，按顺序切换：

**检测中状态**（显示约 0.5-3 秒）：
```
⏳ 检测项 3/9  客户端认证        正在检测...     [灰色]
```

**成功状态**（检测通过后立即切换）：
```
✅ 检测项 3/9  客户端认证        已登录 ✓        [绿色]
```

**失败状态**（检测失败后立即切换）：
```
❌ 检测项 3/9  客户端认证        认证失败 ✗      [红色]  [修复]
```

**跳过状态**（条件不满足时）：
```
⏭ 检测项 8/9  安全启动状态       环境不支持      [灰色]
```

### 3.3 检测结果的显示规格

| 元素 | 规格 |
|------|------|
| 状态图标 | 20x20px，左侧 4px 间距 |
| 检测序号 | 12px，#999，右对齐，宽 80px |
| 检测名称 | 14px，#333，左对齐 |
| 检测结果 | 13px 右对齐，宽度自适应 |
| 行高 | 36px，上下内边距 6px |
| 行背景 | 交替色 #FAFAFA / #FFFFFF |
| 动画 | 新行从底部滑入（0.3s ease-out） |

### 3.4 检测失败后的交互

当检测失败时，该行右侧出现「修复」按钮：

```
❌ 检测项 3/9  客户端认证        认证失败 ✗    [修复]
```

- [修复] 按钮：蓝色文字链接，13px，#1890FF
- 点击修复 → 自动执行修复操作 → 重新检测该项
- 修复成功 → 状态变为 ✅
- 修复失败 → 状态保持 ❌，显示错误详情
- 致命项修复失败 → 弹出「无法继续，建议退出」对话框

### 3.5 环境异常汇总视图

当有检测项失败时，检测完成后不直接进入下一步，而是显示：

```
┌──────────────────────────────────────────────────────────────────┐
│  ⚠ 环境检测完成，发现以下问题                                    │
│                                                                  │
│  ┌──────────────────────────────────────────────────────────────┐│
│  │  ❌ 致命: 客户端认证失败        服务器返回 401             ││
│  │     [修复] [忽略并继续]                                      ││
│  ├──────────────────────────────────────────────────────────────┤│
│  │  ⚠ 警告: 安全启动已开启        可能导致驱动签名问题        ││
│  │     [忽略]                                                   ││
│  └──────────────────────────────────────────────────────────────┘│
│                                                                  │
│  [退出]  [全部修复]  [强制继续]                                   │
└──────────────────────────────────────────────────────────────────┘
```

- 致命项：红色背景条，不可忽略
- 警告项：橙色背景条，可忽略
- 忽略后仍可继续装机
- 强制继续：跳过所有致命项（需二次确认）

### 4.5 镜像缓存状态逻辑

| 状态 | 显示 | 用户操作 | 后台行为 |
|------|------|----------|----------|
| 未缓存 | ⬇️ 需下载 | 点击卡片选择 → 自动开始下载 | 1. 开始 HTTP 下载 |
| 下载中 | ⏳ 60% 3.2MB/s | 可暂停/取消 | 1. 断点续传 2. 实时更新进度 |
| 已缓存 | ✅ 已缓存 | 直接选择使用 | 1. 校验 SHA256 2. 通过即可用 |
| 校验失败 | ❌ 已损坏 | 自动重新下载 | 1. 删除缓存 2. 重新下载 |
| 缓存过期 | ⚠ 需更新 | 点击更新 | 1. 重新下载 2. 覆盖旧缓存 |

### 4.6 搜索与筛选行为

- 搜索：实时过滤（debounce 300ms），匹配名称和标签
- 搜索无结果时显示：「没有找到匹配的镜像，请尝试其他关键词」
- 筛选条件：格式 (WIM/ISO/ESD/GHO)、系统类型 (Win10/Win11/Win7)、架构 (x64/x86)
- 多个筛选条件取交集
- 筛选后无结果时显示：「没有匹配的镜像，请调整筛选条件」

## 14. 数据绑定与刷新逻辑

### 14.1 数据加载时机

| 数据 | 加载时机 | 缓存策略 | 刷新方式 |
|------|----------|----------|----------|
| 镜像列表 | 进入步骤② | 30 秒缓存 | 手动刷新/自动刷新 |
| 磁盘列表 | 进入步骤③ | 不缓存 | 手动刷新 |
| 安装选项默认值 | 进入步骤④ | 不缓存 | 每次加载 |
| 无人值守模板 | 展开配置时 | 60 秒缓存 | 手动刷新 |
| 软件模板 | 展开配置时 | 60 秒缓存 | 手动刷新 |
| 驱动包列表 | 展开配置时 | 60 秒缓存 | 手动刷新 |

### 14.2 数据刷新行为

```
手动刷新:
  [🔄 刷新] → 按钮旋转动画 → 请求 API → 更新列表 → 按钮恢复

自动刷新:
  步骤激活 → 检查缓存是否过期 → 过期则请求 API → 更新列表

后台刷新:
  心跳响应中携带数据变更标记 → 标记变更 → 下次进入步骤时自动刷新
```

### 14.3 镜像列表加载状态

| 状态 | 显示 | 用户操作 |
|------|------|----------|
| 加载中 | 骨架屏（3 个灰色卡片脉冲动画） | 等待 |
| 加载成功 | 镜像列表 | 选择 |
| 加载失败 | 空状态 + 错误提示 + [重试] 按钮 | 重试/退出 |
| 加载为空 | 空状态 + "暂无可用镜像" + [添加镜像] 按钮 | 添加镜像 |
| 部分加载 | 已加载的镜像 + 加载失败的提示 | 使用已加载的 |

## 15. 多显示器与 DPI 适配

### 15.1 DPI 缩放规则

| 系统缩放 | 窗口缩放 | 行为 |
|----------|----------|------|
| 100% | 1x | 标准尺寸 900x640 |
| 125% | 1.25x | 窗口 1125x800，自动缩放 |

- 所有 UI 元素使用相对单位（dp/DIP）
- 字体跟随系统 DPI 缩放
- 图标使用 SVG 矢量图，不缩放失真
- 位图图标提供 1x, 1.5x, 2x 三套

### 15.2 多显示器行为

- 启动时在主显示器居中
- 拖拽到副显示器后保持位置
- 关闭后重新打开 → 在关闭时的显示器位置打开
- 显示器拔出后 → 自动移回主显示器
