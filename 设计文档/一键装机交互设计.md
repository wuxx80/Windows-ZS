## 1. 页面状态与流转

### 1.1 子窗口六种状态

`
[启动] → [环境检测中] → [就绪] → [配置中] → [确认] → [执行中]
                      ↑          ↓          ↓          ↓
                    [环境异常]  [配置冲突]  [校验失败]  [执行失败]
                      ↕          ↕          ↕          ↕
                    [重新检测]  [修正配置]  [重新选择]  [重试/跳过]
`

### 1.2 各状态界面表现

| 状态 | 界面表现 | 用户操作 |
|------|----------|----------|
| 环境检测中 | 加载动画 + 逐项检测清单 + 实时回填结果 | 无操作，可取消 |
| 环境异常 | 红色警告卡片 + 检测失败项 + 修复建议 | 点击"修复"或"忽略继续" |
| 就绪 | 镜像列表 + 磁盘信息 + 选项面板全部可交互 | 自由选择配置 |
| 配置冲突 | 顶部黄色警告条 + 冲突项高亮 + 解决建议 | 选择解决方案 |
| 确认 | 汇总清单弹窗 + 最终确认按钮 | 确认或返回修改 |

| 执行失败 | 红色错误卡片 + 失败原因 + 步骤日志 | 重试/跳过/取消 |
| 完成 | 成功弹窗 + 统计信息 + 操作按钮 | 重启/返回 |

## 2. 步骤一：环境检测

### 2.1 检测项清单（按顺序执行，逐项回填结果）

| 检测项 | 检测方法 | 成功 | 失败 |
|--------|----------|------|------|
| 网络连接检测 | Ping 服务器 IP | 继续 | 尝试备选，全部失败则标记异常 |
| 服务器连通性 | POST /api/v1/auth/client/heartbeat | 正常 | 标记"服务器离线" |
| 客户端认证 | POST /api/v1/auth/client/login | 已登录 | 自动注册或提示 |
| PE 环境识别 | 检测注册表 MININT + winpe.jpg | 获知 PE 版本 | 标记非 PE 环境 |
| 磁盘控制器驱动 | wmic diskdrive | 已驱动 | 提示驱动缺失 |
| 磁盘检测 | 枚举所有物理磁盘和分区 | 磁盘列表 | 无磁盘可用 |
| 启动模式检测 | bcdedit + 注册表 PEFirmwareType | UEFI/Legacy | 未知 |
| 安全启动状态 | 注册表 SecureBoot\State | 开启/关闭 | 不可检测 |
| PE 兼容性 | 版本对比 + 内存检查 | 兼容 | 提示兼容问题 |

### 2.2 环境异常处理

| 异常项 | 严重程度 | 默认行为 | 用户可操作 |
|--------|----------|----------|------------|
| 网络断开 | 致命 | 阻止装机，提示检查网络 | 重试 / 退出 |
| 服务器离线 | 致命 | 阻止装机，显示离线 | 重试 / 退出 |
| 客户端认证失败 | 致命 | 阻止装机，提示重新注册 | 重试注册 / 退出 |
| PE 识别失败 | 警告 | 允许继续，功能受限 | 忽略 / 退出 |
| NVMe 未驱动 | 警告 | 提示驱动缺失 | 注入驱动 / 忽略 |
| 磁盘空间不足 | 警告 | 提示清理空间 | 清理 / 选其他磁盘 |
| 安全启动开启 | 提示 | 仅提示，不阻止 | 忽略 |
| 内存不足 | 警告 | 提示可能影响性能 | 忽略 |

## 3. 步骤二：镜像选择

### 3.1 交互布局

- 左侧主区域：镜像列表卡片（大区域），每项显示名称/版本/格式/大小/标签/缓存状态
- 右侧镜像详情面板：点击镜像后显示详细信息
- 顶部：搜索框 + 筛选下拉
- 每个镜像行右侧：下载按钮（未缓存）/ 进度条（下载中）/ 已缓存标志

### 3.2 镜像缓存机制

状态机：未缓存 → 下载中 → 已缓存 → 校验通过

缓存规则：
- 下载到 X:\\ZS_Installer\\Cache\\
- 下载完成后自动校验 SHA256
- 校验失败自动重新下载
- 支持断点续传（HTTP Range）
- 缓存空间不足时提示清理

## 4. 步骤三：目标磁盘选择

### 4.1 交互布局

- 磁盘下拉选择框：显示所有物理磁盘（型号/类型/容量/分区表格式）
- 分区标签行：当前选中磁盘的分区列表（盘符/大小/已用/文件系统/类型）
- 默认选中当前系统盘（C 盘所在磁盘）
- 磁盘排序：SSD 优先于 HDD，系统盘优先于数据盘

### 4.2 冲突检测

| 冲突 | 检测方式 | 提示 | 用户操作 |
|------|----------|------|----------|
| 目标磁盘是 PE 运行盘 | 检测 PE 的 X 盘对应物理磁盘 | "当前磁盘是 PE 运行盘" | 自动禁用 |
| 有系统分区但未勾选保留数据 | 检测分区类型为 System | "将格式化所有分区" | 确认/取消/勾选保留数据 |
| 有重要数据未备份 | 分区已用空间 > 50GB | "建议先备份" | 确认/取消/勾选备份 |
| 空间不足 | 镜像大小 > 可用空间 | "空间不足" | 选其他分区/清理 |
| UEFI + MBR 磁盘 | 启动模式 UEFI + 磁盘 MBR | "自动转换 GPT" | 确认/取消 |
| Legacy + GPT 磁盘 | 启动模式 Legacy + 磁盘 GPT | "自动转换 MBR" | 确认/取消 |

## 6. 步骤五：冲突检测与确认

### 6.1 确认汇总内容

- 顶部：冲突警告条（致命阻止 / 自动修复 / 需确认）
- 中间：汇总卡片（镜像/磁盘/选项/无人值守模板/软件模板/驱动/优化）
- 底部：返回修改 / 开始装机 按钮

### 6.2 冲突检测逻辑（点击"开始装机"前执行）

`
1. 致命冲突 → 阻止装机，提示原因
   - 目标磁盘是 PE 运行盘
   - 磁盘空间不足
   - 保留数据与自动分区冲突

2. 需确认冲突 → 需用户确认
   - 磁盘有数据未勾选备份
   - 将格式化全盘

3. 自动修复冲突 → 执行时自动处理
   - UEFI+MBR → 自动转换 GPT
   - Legacy+GPT → 自动转换 MBR

4. 兼容性警告 → 仅提示
   - 安全启动状态
   - 内存不足
   - 老版本 PE 兼容性
`

## 7. 步骤六：装机执行流程

### 7.1 完整执行序列

`
Step 1:  创建任务         POST /api/v1/tasks
Step 2:  下载镜像         HTTP GET + Range 断点续传
Step 3:  校验镜像         SHA256 比对
Step 4:  备份用户数据     复制到指定位置
Step 5:  分区/格式化      按分区方案执行 (diskpart)
Step 6:  应用镜像          dism /Apply-Image
Step 7:  注入驱动          dism /Add-Driver /Recurse

Step 9:  修复引导          bcdboot /s /f
Step 10: 写入首次脚本     SetupComplete.cmd + FirstLogon.ps1
Step 11: 重启系统          wpeutil reboot

-- 首次启动后自动执行 --

## 8. 客户端登录认证

### 8.1 完整认证流程

`
1. 客户端启动 → 生成 client_id (MAC+CPU序列号 SHA256 取前12位)
2. POST /api/v1/auth/client/register → 发送注册信息
3. 服务器验证 → 白名单检查 → 自动/手动审核
4. 返回 token + auth_status (approved/pending/rejected)
5. 客户端保存 token 到 C:\\ZS_Installer\\client_auth.json
6. 启动心跳循环 (每30秒 POST /api/v1/auth/client/heartbeat)
7. 心跳返回服务器指令和续期 token
8. 如心跳连续3次失败 → 进入离线模式
`

### 8.2 client_id 生成规则

`
client_id = {客户端类型前缀}-{SHA256(MAC+CPU序列号)前12位}
示例: PE-7A3B2C1D4E5F 或 WIN-A1B2C3D4E5F6
`

### 8.3 Token 管理

- JWT 签发，有效期 24 小时
- 每次心跳自动续期
- 存储路径：C:\\ZS_Installer\\client_auth.json
- 失效后需重新登录

### 8.4 离线模式

触发条件：心跳连续 3 次失败
离线行为：
- 使用本地缓存的镜像列表
- 已下载的镜像仍可安装
- 无法拉取新镜像、无法同步任务
恢复方式：网络恢复后自动重连、补传离线状态

## 9. PE 环境识别机制

### 9.1 检测方法

| 检测项 | 方法 | 关键标识 |
|--------|------|----------|
| 是否 PE | 注册表 MININT 标志 + winpe.jpg 文件 + wpeutil.exe | IsPe: true/false |
| PE 版本 | 注册表 ProductName | Win11PE / Win10PE |
| 架构 | Environment.Is64BitOperatingSystem | x64 / x86 |
| 启动模式 | 注册表 PEFirmwareType | 1=Legacy, 2=UEFI |
| 安全启动 | 注册表 SecureBoot\State | 开启/关闭 |
| 磁盘列表 | WMI 枚举 | 物理磁盘 + 分区 |

### 9.2 PE 盘符映射规则

PE 启动后盘符会发生变化：
- PE 运行盘 → X: (RAM Disk)
- 原系统盘 C: → 可能变为 D: 或 E:
- 原数据盘 → 盘符后移

系统盘识别算法：
1. 遍历所有驱动器，检测是否存在 Windows 目录
2. 或加载 SOFTWARE 配置单元读取 CurrentVersion
3. 或解析 BCD 存储中的 osdevice 分区

### 9.3 兼容性检测

| 条件 | 检测 | 结果 |
|------|------|------|
| Win11PE → 安装 Win10/11 | 兼容 | 通过 |
| Win10PE → 安装 Win7/8/10 | 兼容 | 通过 |
| Win10PE x86 → 安装 x64 系统 | 不兼容 | 阻止 |
| 内存 < 4GB | 可能性能不足 | 警告 |
| 磁盘空间 < 镜像大小 x 2 | 空间不足 | 阻止 |

## 11. 异常处理与恢复

### 11.1 异常等级

| 等级 | 定义 | 行为 |
|------|------|------|
| 致命 | 无法继续 | 停止装机，标记失败，回滚已执行步骤 |
| 严重 | 可跳过影响结果 | 提示用户，可跳过或重试 |
| 警告 | 不影响结果 | 记录日志，继续执行 |

### 11.2 各步骤异常处理

| 步骤 | 异常 | 等级 | 处理方式 |
|------|------|------|----------|
| 下载镜像 | 网络中断 | 严重 | 自动重试3次，支持断点续传 |
| 下载镜像 | 磁盘空间不足 | 致命 | 停止，提示清理 |
| 校验镜像 | Hash 不匹配 | 严重 | 自动重新下载 |
| 备份数据 | 文件无法复制 | 严重 | 记录失败清单，继续 |
| 分区 | 磁盘锁定 | 严重 | 尝试解锁，失败提示手动 |
| 应用镜像 | WIM 损坏 | 致命 | 重新下载镜像 |
| 注入驱动 | 签名问题 | 严重 | 跳过该驱动继续 |
| 引导修复 | BCD 创建失败 | 严重 | 尝试手动修复模式 |
| 重启 | 无法重启 | 严重 | 提示手动重启 |

### 11.3 回滚机制

- 使用栈结构记录可回滚操作
- 每个步骤执行前注册反向操作
- 分区操作不可逆（标记为不可回滚）
- 回滚失败记录日志但继续

### 11.4 断点续传与恢复

任务状态持久化到 C:\\ZS_Installer\\task_state.json，包含：
- 已完成步骤列表
- 当前步骤和错误信息
- 下载进度（支持续传）
- 备份清单

恢复逻辑：根据已完成步骤从失败点继续执行。

## 17. 边缘场景处理

### 17.1 镜像下载中断

| 场景 | 处理方式 | 用户体验 |
|------|----------|----------|
| 网络中断 | 自动重试 3 次，间隔 5 秒 | 显示"重试中..." |
| 服务器断开 | 自动切换到备用服务器 | 显示"切换服务器..." |
| 磁盘空间不足 | 停止下载，提示清理 | 显示"空间不足，请清理" |
| 用户取消下载 | 删除已下载的部分文件 | 返回镜像选择界面 |
| 断电恢复 | 读取任务状态文件，从断点续传 | 显示"恢复下载中..." |

### 17.2 镜像校验失败

| 场景 | 处理方式 |
|------|----------|
| SHA256 不匹配 | 自动重新下载，最多 3 次 |
| 文件大小不符 | 标记为损坏，提示重新下载 |
| 无法校验（无 Hash） | 提示"无法校验，继续使用有风险" |
| 文件被占用 | 提示关闭其他程序 |

### 17.3 磁盘操作异常

| 场景 | 处理方式 | 恢复措施 |
|------|----------|----------|
| 分区表损坏 | 尝试重建分区表 | 使用 testdisk 恢复 |
| 磁盘写保护 | 提示移除写保护 | 物理检查开关 |
| 扇区错误 | 标记坏道，跳过 | 建议更换硬盘 |
| 磁盘锁定 | 强制解锁 | diskpart clean |
| 意外断电 | 开机后检查分区状态 | 恢复到上次已知状态 |

### 17.4 多重启动冲突

| 检测项 | 冲突 | 处理方式 |
|--------|------|----------|
| 已安装 Ubuntu | 双系统共存 | 提示"将覆盖 GRUB 引导" |
| 已安装 macOS | Hackintosh 引导冲突 | 提示"需要手动修复引导" |
| BitLocker 加密 | 无法读取分区 | 提示"需要先解密" |
| 动态磁盘 | 无法直接安装 | 提示转换为基本磁盘 |
